Core Workflow

From Jira URL to shippable stories

Paste a Jira epic URL. The AI pipeline handles the rest — discovery, clarification, PRD generation, story decomposition, and sync back to Jira.

1
Jira Ingestion
Full ticket tree fetched via OAuth — root epic, child stories, comments, attachments (with PDF text extraction).
2
AI Discovery — 4 Passes
Ambiguity scan → Missing info → Edge case gaps → Compliance gaps. Each pass builds on prior findings.
3
PM Answer Loop
Ranked clarification questions surface to the PM. HIGH-severity questions are required before continuing.
4
PRD Generation
24-section enterprise PRD generated section-by-section with a running decisions log to maintain coherence.
5
Story Hierarchy
Initiative → Epic → Feature → Story → Task. Every story gets Given/When/Then criteria and edge cases.
6
Jira Sync
Stories pushed back to Jira with rate limiting and idempotency. Webhook events keep both sides current.

Multi-Agent Architecture

Specialized agents. One orchestrator.

Each agent is a LangGraph subgraph with defined input/output contracts, retry logic, and token-cost tracking. The supervisor routes tasks based on workflow state stored in PostgreSQL.

Orchestrator Agent (LangGraph supervisor) │ ┌──────────────────────────────┼──────────────────────────────┐ Discovery Agent Incident Agent Delivery Agent │ │ │ PRD Agent Handover Agent Risk Agent │ │ │ Story Agent QA Agent GIS Agent (Phase 3)
DiscoveryAgent
4-pass analysis: ambiguity, missing info, edge cases, compliance gaps. Generates PM clarification questions ranked by severity.
PRDAgent
Section-by-section PRD synthesis with a running decisions log. Coherence review pass before marking complete. Uses Claude Opus.
StoryAgent
Decomposes PRD into Initiative → Task hierarchy. Given/When/Then acceptance criteria and edge cases per story.
IncidentAgent
Executive + operator incident summaries. Chronological timeline construction. Pattern detection across incident sets.
RiskAgent
Scores risks by likelihood × impact across 5 types. Generates concrete mitigations. Aggregate score per entity.
HandoverAgent
AI shift handover reports: unresolved incidents, active escalations, pending actions, high-risk areas for incoming shift.
